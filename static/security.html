Security & Privacy

How we protect your data. Last updated: July 3, 2026.

Your data is not used to train AI models

Your architecture description is sent to Google's Gemini API solely to produce your result. Per Google's API terms, data submitted through the Gemini API is not used to train their models. We do not use your data to train any model, and we do not sell your data.

Tenant isolation

Each account's data is isolated at the database level using PostgreSQL Row-Level Security. Users can only ever access their own data — enforced by the database itself.

Encryption

  • All data encrypted in transit (TLS/HTTPS).
  • All data encrypted at rest (managed PostgreSQL via Supabase).

Authentication

We authenticate via Google OAuth. We never see or store your password. Sessions use signed, expiring JWTs verified on every request.

Audit logging

Every action that creates, approves, rejects, or deletes data is recorded in an append-only audit log.

Human-in-the-loop

AI-generated threats are proposals. Nothing counts as compliance evidence until a human on your team explicitly approves it. AI is an assistant, not the authority.

Data deletion

You can delete any project at any time. Deleting a project permanently removes its threats and mitigations.

Subprocessors

  • Supabase — database, authentication (SOC 2 compliant)
  • Google Gemini API — AI inference (does not train on API data)
  • Render — application hosting (SOC 2 compliant)

Compliance posture

This product is built to align with SOC 2 controls. We are SOC 2-ready; formal certification is on our roadmap.
